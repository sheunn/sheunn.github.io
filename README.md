## Projects

### Smart Mirror

AI 기반 면접 피드백 시스템

- 실시간 얼굴 표정 분석
- 음성 톤 분석
- 면접 결과 및 피드백 제공
- MobileNetV2 기반 표정 분류 모델 개발
- MediaPipe를 활용한 얼굴 영역 추출
- ONNX 기반 실시간 추론 구현
- FastAPI와 React를 활용한 서비스 구현

**Tech Stack**

`Python` `PyTorch` `MediaPipe` `ONNX` `FastAPI` `React` `PostgreSQL`

### TrustEye

AI 기반 가짜 리뷰 탐지 및 리뷰 분석 서비스

- 리뷰 클러스터링 및 요약
- 신뢰도 기반 보정 평점 제공

**Tech Stack**

`Python` `SBERT` `Scikit-learn` `SQLite` `K-Means` `LLM`
